### Цель проекта
Создать на одной Linux-ВМ воспроизводимый лабораторный стенд, который принимает синтетические BGP-анонсы и NetFlow, сопоставляет адреса потоков с BGP-префиксами с помощью pmacct, сохраняет обогащённую статистику в PostgreSQL и показывает её в Grafana. Проект реализован для последующего его внедрения в СПД компании. 
### Общее описание стенда
Техническая информация стенда:

| Часть стенда |      Версия      | Примечание |
| :----------: | :--------------: | :--------: |
|  ОС стенда   | Ubuntu 24.04 LTS |     -      |
|    ExaBGP    |                  |            |
|    pmacct    |                  |            |
|    Python    |                  |            |
|    Scapy     |                  |            |



Данный лабораторный стенд представляет собой виртуальную машину, на которой создан изолированный `NamSpace` **Border**, сетевая связность с которым осуществляется с помощью `veth` интерфейсов **veth-host** и **veth-Border**. IP адрес **veth-host** - `192.0.0.1`, IP **veth-Bordert** - `192.0.0.2`. На ВМ работает демон `BIRD`, который осуществляет соединение с **NS Border** в соответствии с конфигурацией */etc/bird/bird.conf*. Со стороны **NS Border** работает в окружении `venv` `ExaBGP`, окружение находится */opt/exabgp-env*. В конфигурации `ExaBGP` прописываются маршруты для инжекции в `pmacct`. AS host - `65001`, AS Border - `65002`. В качестве потока Netflow создан скрипт на python, который с помощью библиотеки Scapy создает синтетические Netflow на основе статических маршрутов. Данный скрипт развернут в окружении */opt/netflow-env*.
