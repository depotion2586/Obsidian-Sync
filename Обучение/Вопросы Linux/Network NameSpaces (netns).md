#Обучение; 
Можно назвать виртуальной сетевой картой. Каждый NameSpace имеет свою отдельную:
- Таблицу маршрутизации
- Набор портов
- Фаервол
- Подсети
При этом ни один NameSpace не будет знать о другом. Можно на каждой из этих изолированных виртуальных сетевых карт использовать одни и те-же ip адреса, порты и.т.д
### Применение:

1. Является базой Docker. Каждый контейнер запускается в рамках конкретной изолированной виртуальной сетевой карты. 
2. Может быть использован для VPN на отдельных приложений. Каждое использует свою виртуальную сетевую карту.
3. Есть возможность соединять между собой разные NameSpaces с помощью [[Veth Pairs]], таким образом эмулируя работу нескольких сетевых устройств на одной машине.
