## Основные команды

`git reset хэш_коммита` — Отмена изменений и откат назад
	Эта команда перемещает вашу текущую ветку назад на указанный коммит. У неё есть три ключевых режима (флага), которые кардинально меняют её поведение:

`git rebase` — Перенос истории
	Альтернатива команде `git merge`. Если `merge` соединяет две ветки, создавая новый «коммит слияния», то `rebase` берёт коммиты из вашей ветки и «пересаживает» их на верхушку другой ветки.

`git revert хэш_коммита` — Безопасная отмена коммита
	В отличие от `reset`, она не удаляет старый коммит из истории. Вместо этого она создает новый коммит, который делает строго противоположные действия (удаляет то, что было добавлено, и возвращает то, что было удалено). Идеально для работы в команде.

`git checkout хэш_коммита_или_название_ветки` — Посмотреть на файлы из прошлых коммитов
	Позволяет временно переключиться на любой коммит из прошлого, чтобы посмотреть, какими были ваши файлы в тот день. Чтобы вернуться обратно в настоящее `git switch main`.
