## Просмотр текущего состояния и положения

`git status` — Общая информация
	Показывает, на какой вы ветке, есть ли измененные файлы, какие из них готовы к коммиту (зеленые), а какие еще не отслеживаются (красные).

`git branch` — Список веток
	Показывает все локальные ветки в проекте. Та ветка, перед которой стоит звёздочка **`*`** и которая выделена цветом — текущая. 

`git remote -v` — Куда отправляются файлы
	 Показывает адрес удаленного репозитория (например, ссылку на ваш GitHub), к которому привязан локальный Git. 
## История и статистика коммитов

`git log` — История коммитов
	Выводит список всех сделанных коммитов с их ID (хэшем), автором, датой и текстом сообщения. Чтобы выйти из этого режима просмотра, нажмите клавишу **`Q`** на клавиатуре.
`git log --oneline` — Увидеть хэш коммита, который нужен в истории

## Жизненный цикл внесения изменений

1. `git add .`  Добавить все измененные и новые файлы в текущей папке в индекс.
2. `git commit -m "Изменения"` Создать коммит подготовленных файлов.
3. `git push origin main` Отправить локальные сохраненные коммиты в ветку `main`.
4. `git pull --rebase` Забрать свежие изменения с GitHub в свой локальный компьютер, не стирая и не применяя `merge` к уже сделанным изменениям.

## Первичная настройка

Git должен знать, кто делает сохранения, иначе он заблокирует коммит.

**`git config --global user.name "Ваше Имя"`** — Имя автора 
    Задает имя, которое будет отображаться в истории коммитов на GitHub.

**`git config --global user.email "your_email@example.com"`** — Почта автора. 
    Привязывает коммиты к вашему профилю GitHub (укажите почту от вашего аккаунта).

**`git checkout -b main origin/main`** — Создание и переключение в ветку main
    полезно на новом устройстве без коммитов для быстрого переключения на `main` без создания коммитов

**`git remote add origin [ссылка на репо]`** — Связывание с сервером
	После связки что бы пушить что либо в репозиторий необходимо авторизоваться. Это можно сделать заранее, прописав далее команду **`git remote set-url origin https://depotion2586:[PAT]@github.com/depotion2586/[НАЗВАНИЕ_РЕПОЗИТОРИЯ]`** — Автоматически провести авторизацию по [PAT] токену для будущих пушей без авторизации.

**`git config --global credential.helper manager`** — Активация менеджера учетных данных
	При установке Git for Windows эта настройка обычно применяется по умолчанию. Чтобы принудительно указать Git использовать системное хранилище Windows (и ни в коем случае не сохранять токен в файлах проекта)

**`git push -u origin main`**  
    **Первая выгрузка.** Отправляет ваш локальный коммит на сервер GitHub в ветку `main`. Флаг `-u` (upstream) связывает вашу локальную ветку `main` с веткой `main` на GitHub. В будущем вам достаточно будет писать просто `git push` без указания веток.
