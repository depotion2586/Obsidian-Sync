**Определение:** NameSpace - это не сетевая карта, это виртуальный контейнер для сетевых карт, будь то виртуальные сетевые карты такие как: (lo, veth, dummy) или физические. Каждый NameSpace имеет свою отдельную:
- Таблицу маршрутизации
- Набор портов
- Фаервол
- Подсети
При этом ни один NameSpace не будет знать о другом. Можно на каждой из этих изолированных сред использовать одни и те-же ip адреса, порты и.т.д
### Примеры использования

1. Является базой Docker. Каждый контейнер запускается в рамках конкретной изолированной виртуальной сетевой карты. 
2. Может быть использован для VPN на отдельных приложений. Каждое использует свою виртуальную сетевую карту.
3. Есть возможность соединять между собой разные NameSpaces с помощью [[Veth Pairs]], таким образом эмулируя работу нескольких сетевых устройств на одной машине.

### Эксплуатация NameSpaces
Что бы запустить что либо в рамках изолированной виртуальной сетевой карты необходимо выполнить список следующих [[#^b01e15|команд]].
**Примечание(1):** можно помещать или перемещать физические сетевые карты внутрь виртуальной изолированной среды. Сделать это можно [[#^b01e15|так]]. 


### Как создавать, управлять NameSpaces:
**Общие команды NS:**
	`ip netns list` - список существующих NameSpaces
	`ip netns add ИМЯ_NAMESPACE` - создание нового NS с названием `ИМЯ_NAMESPACE` 
	`ip netns del ИМЯ_NAMESPACE` - удаление существующего NS с названием `ИМЯ_NAMESPACE`
**Команды для эксплуатации NS**
	`ip netns exec ИМЯ_NAMESPACE ip link` - посмотреть сетевые интерфейсы внутри NS с названием `ИМЯ_NAMESPACE`
		**Примечание(1):** В выводе данной команды у каждой изолированной среды будет один lo интерфейс и он будет выключен. Его необходимо обязательно включить *(удобнее всего это делать внутри оболочки Bash самой среды)* командой: 
		`ip link set lo up`
	`ip netns exec ИМЯ_NAMESPACE bash` - открыть оболочку внутри NS с названием `ИМЯ_NAMESPACE` для выполнения любых команд в рамках данной изолированной сетевой карты.
	`ip netns exec NS ip route show || ip route show` - команда, находясь в домашней оболочке || находясь внутри NS с названием `NS`. Просмотр всей таблицы маршрутизации изолированной среды.%%^b01e15%%
	`ip link set ИМЯ_ИНТЕРФЕЙСА netns ИМЯ_NAMESPACE` - поместить интерфейс сетевой карты внутрь виртуальной изолированной среды.
		**Примечание(2):** после этого интерфейс необходимо включить - `ip link set lo up` а также выдать IP адрес - `ip addr add x.x.x.x/x dev ИМЯ_ИНТЕРФЕЙСА`
